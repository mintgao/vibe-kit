# Vibe Kit v0.9.0

This is the selected non-draft GitHub Pre-release candidate. Public completion is recorded only after live verification.

## Changes

- Read-only `validate-readiness` checks newly adopted M/L briefs and real Accepted ADR/review files before implementation release. Implemented notes and malformed or unsafe evidence fail closed.
- Read-only `inspect-managed-agents` authenticates the managed AGENTS byte span; an explicitly selected unicode-whitespace-v1 ceiling counts the whole merged file. Managed prose uses one physical line per paragraph, with project-owned bytes and policies preserved.
- Every release reviews both GitHub homepages for changed version, links, commands, capabilities and limitations.
- Exact publication schema 3 binds v0.9.0 to six operations and five assets. Separate closeout schema 2 permits only #6/#7 after public verification. Historical v0.7/v0.8 profiles retain their boundaries.

## Compatibility and limits

Kit 0.9.0 uses core/Codex protocol 7 and Python 3.9+. Existing Agent-install, takeover, maintenance bridge, manifest, transaction and general CLI result schemas retain their meanings. Healthy v0.3/v0.5/v0.6/v0.7/v0.8 predecessor smokes remain required for public verification. Source doctor proves installation integrity, not runtime activation.

The CLI does not lock filesystem writes, authenticate human review or host consent, silently adjust budgets, implement arbitrary project counting rules, publish over the network, or provide publisher signatures.

The five public assets are SHA256SUMS, release-manifest.json, vibe-kit-0.9.0.zip, vibe-kit-distribution-0.9.0.zip and vibe-kit-plugin-0.9.0.zip. No stable promotion or Plugin Directory publication is included.
