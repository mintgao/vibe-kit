- Status: `prerelease`
- Repository: <https://github.com/mintgao/vibe-kit>
- Release: <https://github.com/mintgao/vibe-kit/releases/tag/v0.5.0>
- Date: 2026-08-27

## Agent-first adoption

- Codex can discover the packaged `AGENT_INSTALL.md` and `agent-install.json` contract from the canonical GitHub repository or a verified payload.
- The contract keeps source selection, safe plan/apply, doctor, handoff and automatic onboarding inside the Agent flow. Humans continue with ordinary development language.
- Install-critical commands provide additive result-schema version 1 JSON while retaining default text output and existing exit behavior.
- Install and upgrade receipts record validated source type, immutable ref and artifact SHA-256 when supplied.
- Fresh installs create project-owned `.vibe/onboarding.json` as `pending`; upgrades preserve it, doctor reports readiness, and managed instructions resume the original request after evidence-backed onboarding.

## Technical decision readiness

- M/L feature, debug-to-fix, and direct implementation work now checks durable/high-risk technical decisions before the first shared-code edit.
- L and triggered M work fail closed until governing decisions, required independent review, material product decisions, blockers, and orchestrator confirmation satisfy the project-owned readiness record.
- A read-only Tech Lead perspective owns decision evidence and review; one RD writer implements only after `implementation-ready`, while QA remains an independent post-implementation acceptance perspective.
- The gate is a repository workflow contract distributed through managed files. The CLI hash-checks those files but does not claim to enforce Agent behavior mechanically.

## Protocols and compatibility

- Kit version: `0.5.0`
- Core protocol: 3
- Codex adapter protocol: 3
- Agent install protocol: 1
- Feedback protocol: 2
- Python runtime: 3.9 or later, standard library only

The CLI remains offline. Remote Release resolution and digest verification belong to Codex/the host permission boundary. Only the canonical `mintgao/vibe-kit` repository is trusted by default; moving refs and silent pre-release selection remain blocked.

## Build and verify

```bash
./bin/vibe doctor .
python3 -m unittest discover -s tests -v
./bin/vibe package --status prerelease
./bin/vibe validate-release dist/vibe-kit-0.5.0
```

The GitHub bundle is built from the clean annotated release commit, exposes the release ZIP, bootstrap Plugin ZIP, full distribution ZIP, release manifest and checksums, and is verified again after an isolated download.

## Release boundary

- 0.5.0 is a GitHub Pre-release, not a stable release or public Plugin Directory version.
- Real Linux, non-Codex adapters, live task handoff, and live Plugin-host behavior do not have complete conformance evidence and are not inferred from macOS/source-artifact tests.
- Install and upgrade are not whole-directory transactions. A post-mutation filesystem failure reports conservative `unknown-partial` recovery state; the separately shaped permission-safe atomic-upgrade work is not included in this release.
- SHA-256 metadata proves asset/content consistency, not an external publisher signature or provenance attestation.
