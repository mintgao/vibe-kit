# Vibe Kit v0.10.1

This is the selected non-draft GitHub Pre-release candidate. Public completion is recorded only after live verification.

## Changes

- The Hermes host label reads `verified`, backed by its completed five-stage conformance record: a genuinely new Hermes task admitted this repository's existing installation over the manual-new-task path, its takeover object validated structurally, and the record cites the command results and artifact digests. The label is descriptive; no operation is gated by it, and the unknown-host and incoherent-selection rules stay fail-closed.
- Exact publication schema 5 binds v0.10.1 to six operations, five assets and no issue closeout. Historical v0.7/v0.8/v0.9/v0.10.0 profiles retain their boundaries, a v0.10.1 candidate never passes them, and the separate schema-3 closeout stays bound to the historical v0.10.0 parent.
- The maintenance bridge admits installed versions from 0.2.0 up to, but not including, 0.10.1, and the `v0.5.0-unmanaged-agent-contracts-v1` migration target moves with the version, so a healthy recorded 0.10.0 install and the bridgeable older installs upgrade into this candidate.

## Compatibility and limits

Kit 0.10.1 uses core/Codex protocol 7 and Hermes adapter protocol 1 and requires Python 3.9+. The Agent-install contract itself stays schema/protocol 4, takeover schema 2, and the maintenance bridge schema 2; installed Agent-install protocols 0–3 stay upgradeable. Healthy v0.3/v0.5/v0.6/v0.7/v0.8/v0.9 and v0.10.0 predecessor smokes remain required for public verification. Source doctor proves installation integrity, not runtime activation.

The CLI does not lock filesystem writes, authenticate human review or host consent, perform network writes, publish over the network, or provide publisher signatures. No live same-task reload or automatic successor handoff is claimed for either host; both remain manual-fallback-only for upgrade activation until a host supplies a conforming live receipt. The Codex five-stage refresh under the schema-4 contract remains a tracked follow-up, and no Codex execution is claimed here.

This release contains no product change beyond the host label and the version identity. GitHub issues #14 (`validate-publication --receipt` rewrites its input receipt with the result envelope) and #15 (re-running `upgrade` on an already-current install fails target postimage validation and rolls back) stay open tracked defects.

The five public assets are SHA256SUMS, release-manifest.json, vibe-kit-0.10.1.zip, vibe-kit-distribution-0.10.1.zip and vibe-kit-plugin-0.10.1.zip. No stable promotion or Plugin Directory publication is included.
